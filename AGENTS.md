# AGENTS.md — для AI-агентов и разработчиков

## Что это

`devtool-script` — **только лаунчер** `dev` (один файл `bin/dev`, чистый Bash 4+).
Скриптов в этом репозитории нет и не должно быть. Они лежат в пакетах:

- `$DEV_SCRIPTS_HOME/<пакет>/` (по умолчанию `~/.dev-scripts/`) — каждый пакет отдельная папка, обычно свой git-репозиторий;
- `$PWD/.dev/` — пакет `project` текущего проекта (имеет высший приоритет).

## Правила лаунчера

- Путь файла внутри пакета = команда: `git/tag.sh` → `dev git tag`. Вложенность любая.
- Файлы и папки на `.` или `_` игнорируются (`_lib/` — общий код пакета).
- Метаданные в шапке, все необязательны: `# @desc`, `# @usage`, `# @dangerous true|false`,
  `# @complete a b c` (варианты аргументов для Tab)
  (старые `@description` и `@name` тоже читаются).
- `@dangerous true` → подтверждение `[y/N]`, пропускается флагом `dev -y`.
- Скрипт запускается как `bash <file> <аргументы>`; `chmod +x` не обязателен.
  В окружении: `DEV_PACK_DIR`, `DEV_SCRIPTS_HOME`, `DEV_FORCE`.
- Разрешение имени: самое длинное совпадение по словам → уникальное последнее слово → меню папки.
- Встроенные (зарезервированные) слова: `new create edit list ls help packs add update doctor completion` (+ служебные `_complete`, `_preview`).
- Автодополнение: `dev _complete [--zsh] <слова>` печатает варианты следующего слова; `dev completion bash|zsh` — обёртка для оболочки.

## Как добавить скрипт (агенту)

1. Убедиться, что это не тривиальный однострочник (`git status`, `npm start` — не нужно).
2. Создать через лаунчер, а не вручную:
   ```bash
   dev new <папка> <команда> -p <пакет> -d "Описание" [--dangerous] --no-edit
   ```
3. Написать логику в созданном файле: `set -euo pipefail`, проверять утилиты (`need docker`),
   не хардкодить пути хоста, всё разрушительное — `@dangerous true`.
4. Закоммитить **в репозитории пакета**, а не в `devtool-script`.

## Как менять сам лаунчер

- Всё в `bin/dev`; без внешних зависимостей кроме `git` (и опционального `fzf`).
- Проверка: `bash -n bin/dev`, затем прогон с временным `DEV_SCRIPTS_HOME=<tmp>`.
- `install.sh` — установка ядра (`~/.devtools` + ссылка в `~/.local/bin`), `--pack <url>` подключает пакеты.
